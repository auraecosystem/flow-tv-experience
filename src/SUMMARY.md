# Flow TV Experience - Comprehensive Project Summary

**Flow TV Experience** is an interactive web-based television simulator blending 90s CRT aesthetics with generative AI capabilities.

## Technical Architecture
* **Frontend Frame**: Single HTML5 file (Vanilla JS, HTML5 Canvas, Tailwind CSS)
* **LLM Engine**: gemini-3-flash-preview (Text, Search Grounding, Contextual Chat)
* **Neural Voice Synthesis**: gemini-2.5-flash-preview-tts (PCM audio synthesis)

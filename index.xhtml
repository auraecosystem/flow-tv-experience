Key Application Features

                    
                    

                        

                            📺 CRT Procedural Shaders
                            Canvas 2D
                        

                        
Dynamic Synthwave grid, Cyber Matrix rain code, 90s Anime starfield, and SMPTE color test card rendered without static video assets.

                    


                    

                        

                            🎙️ Gemini Neural Voice Announcer
                            gemini-2.5-flash TTS
                        

                        
Generates contextual station warnings and converts text into high-fidelity neural speech audio.

                    


                    

                        

                            🧠 Grounded TV Channel Guide
                            Search Grounding
                        

                        
Performs real-time search queries to summarize cultural context and background lore for any channel feed.

                    

                


                
                

                    

                        
Local Setup Instructions

                        

                            
# 1. Clone the repository

                            
git clone https://github.com/your-username/flow-tv-experience.git

                            
                            
# 2. Navigate and start local server

                            
cd flow-tv-experience && npm start


                            
# 3. Open browser URL

                            
http://localhost:3000

                        

                    


                    

                        
🔑 Gemini API Key Configuration

                        
To unlock full AI voice and schedule prediction, open index.html and set your key in const apiKey = "YOUR_KEY".
